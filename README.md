# Табло дедлайнов — Telegram-бот

Пересылаешь боту сообщения заказчика, и он сам делает из них карточку на украинском:

```
📌 Задача #12

Суть задачі: Логотип для кавʼярні, 3 варіанти, формат SVG
Дедлайн: 30.10.2026 (пт), 18:00 — через 3 дн.
Ціна: 1500 грн
Профіль замовника: Олена (@olena)   ← ссылка на профиль
[✅ Здано] [✏️ Дедлайн] [🗑 Видалити]
```

- **Суть, дедлайн, цену** вытаскивает Claude (Anthropic API). Относительные даты («до пятницы», «через неделю») считаются от того дня, когда заказчик написал сообщение.
- **Профиль заказчика** берётся из данных пересылки (имя, @username, ссылка). Если заказчик скрыл аккаунт при пересылке, будет только имя.
- Можно переслать **несколько сообщений подряд** или добавить свой комментарий с датой: всё, что пришло в течение ~2,5 секунд, попадает в одну задачу. Твоя дата важнее той, что в сообщении.
- Если дедлайна нет, бот попросит его: просто ответь «пятница 18:00» или «5.11».
- **Каждое утро** (по умолчанию в 09:00 по Киеву) бот присылает список всех активных дедлайнов.
- **Напоминания**: за сутки до дедлайна и за 3 часа до него. Если в дедлайне только дата без времени, напоминания приходят в 09:00 накануне и в 09:00 в день сдачи.
- `/list` — все дедлайны в любой момент, `/t12` — открыть задачу №12.
- Бот отвечает только тебе (`OWNER_ID`).

Закрепи чат с ботом вверху списка, и все дедлайны будут в одном закреплённом чате.

## Запуск

1. Создай бота у [@BotFather](https://t.me/BotFather) (`/newbot`) и скопируй токен.
2. Получи ключ Claude API: https://platform.claude.com/settings/keys
3. Настрой и запусти:

   ```bash
   cp .env.example .env        # впиши TELEGRAM_BOT_TOKEN и ANTHROPIC_API_KEY
   python3 -m venv .venv && . .venv/bin/activate
   pip install -r requirements.txt
   python -m deadline_bot
   ```

4. Напиши боту `/start`: он пришлёт твой Telegram ID. Впиши его в `OWNER_ID` в `.env` и перезапусти бота.

### Чтобы работал 24/7

Напоминания приходят, только пока бот запущен, поэтому его нужно держать на сервере (VPS, Railway, Fly.io и т. п.). С Docker:

```bash
docker build -t deadline-bot .
docker run -d --restart=always --env-file .env -v $(pwd)/data:/app/data deadline-bot
```

Задачи хранятся в SQLite (`data/tasks.db`), так что после перезапуска ничего не теряется.

## Настройки (`.env`)

| Переменная | По умолчанию | Что это |
|---|---|---|
| `TIMEZONE` | `Europe/Kyiv` | Часовой пояс |
| `DIGEST_TIME` | `09:00` | Время утреннего списка |
| `SOON_HOURS` | `3` | За сколько часов до дедлайна второе напоминание |
| `DB_PATH` | `tasks.db` | Файл базы данных |
| `CLAUDE_MODEL` | `claude-opus-5-5` | Модель для разбора сообщений |

Запросы к Claude идут с `fallbacks: "default"`: если модель откажется обрабатывать сообщение, API само повторит запрос на запасной модели. Если разобрать сообщение всё равно не удалось, бот сохранит текст как есть, и дедлайн можно поставить кнопкой «✏️ Дедлайн».
