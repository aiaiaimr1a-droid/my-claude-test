# Бот-агрегатор заказов на студенческие работы

Собирает заказы из Telegram-групп, отсеивает рекламу авторов и дубли и публикует их
в **платный канал**. Контакт заказчика открывается через бота, и только у ограниченного
числа авторов (по умолчанию 5), после чего заказ помечается «✅ Набран».
Если нужно, заказы дублируются в **бесплатный канал-витрину** с задержкой, без контакта и бюджета.

```
 группы, где есть бот ──┐
                        ├─► фильтр ─► дубли ─► платный канал ──(сразу)
 группы юзербота ───────┘                    └► бесплатный канал ─(через N часов, без контактов)

 автор жмёт «Открыть контакт» ─► бот: проверка подписки ─► лимит ─► контакт в личку
```

## Канал или чат?

**Лучше канал.** Его и сделать быстрее.

| | Канал | Группа (чат) |
|---|---|---|
| Лента | Только заказы, ничего лишнего | Тонет в сообщениях и флуде |
| Перехват контактов | Авторы не могут писать под заказом | Авторы перебивают друг друга, студента видно всем |
| Платный доступ | Нативная подписка за Stars работает | Только через сторонних ботов |
| Лимит откликов | Работает (кнопка ведёт в бота) | Легко обойти |

Общение авторов между собой лучше вынести в отдельную группу при платном канале
(«закрытый чат авторов»). Это удерживает людей в подписке, когда заказов мало.

## Откуда бот берёт заказы: два источника

1. **Бот (Bot API)** читает только группы, куда его добавили. Подходит для своих чатов
   и чатов, админы которых согласились. Это официально и надёжно.
2. **Юзербот (Telethon)** — обычный аккаунт Telegram, состоящий в группах. Читает
   чужие студенческие чаты, куда бота не пустят.
   - Использует аккаунт как программа. Telegram это разрешает, но аккаунты за подозрительную
     активность иногда банят. **Берите отдельный номер, не основной.**
   - Юзербот только читает, публикует основной бот. Риск небольшой.
   - Помните, что вы забираете контакты людей из чужих чатов. Если админ чата против,
     такое станет поводом для жалоб на ваш канал.

Можно включить оба источника сразу: дубли отсекаются по тексту.

## Запуск за 15 минут

### 1. Создать бота
1. [@BotFather](https://t.me/BotFather) → `/newbot` → получить токен.
2. **Важно:** `/setprivacy` → выбрать бота → `Disable`. Иначе в группах бот видит только команды.
   (Если бот уже был в группе, удалите его и добавьте снова, чтобы настройка применилась.)

### 2. Создать каналы
1. Приватный канал «Заказы» (платный). Добавьте бота **администратором** с правом публиковать
   и редактировать сообщения.
2. По желанию публичный канал-витрина. Бот тоже админ.
3. ID канала: перешлите любой пост из канала боту [@userinfobot](https://t.me/userinfobot).
   ID будет вида `-100…`.

### 3. Платная подписка
Канал → Управление → Пригласительные ссылки → Создать → **Ежемесячная плата (Stars)**.
Эту ссылку вставьте в `SUBSCRIBE_URL`. Кто оплатил, становится участником канала, и бот
это проверяет, прежде чем выдать контакт.

На старте можно просто впускать авторов бесплатно по обычной ссылке: бот проверяет только
членство в канале, а не факт оплаты.

### 4. Установить и запустить
Нужен Python 3.10+.

```bash
cd order_bot
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env             # заполнить значения
python -m bot.main
```

### 5. Добавить источники
- **Бот:** добавьте его в группы. Админом быть не нужно, если privacy отключён.
- **Юзербот:** заполните `API_ID`/`API_HASH` (с [my.telegram.org](https://my.telegram.org)),
  при первом запуске введите в консоли номер и код. `USERBOT_CHATS` можно оставить
  пустым (слушать все группы аккаунта) или перечислить нужные.

### 6. Проверка
Напишите в группе-источнике: `Нужна курсовая по праву до пятницы, бюджет 1000 грн`.
Заказ должен появиться в канале. В личке с ботом `/stats` показывает статистику (только админам).

## Где держать бота 24/7

- **VPS** (Hetzner, DigitalOcean, украинские хостинги) за $4–5 в месяц. Самый надёжный вариант.
  Пример юнита systemd:

  ```ini
  # /etc/systemd/system/orderbot.service
  [Unit]
  Description=Order aggregator bot
  After=network.target

  [Service]
  WorkingDirectory=/opt/order_bot
  ExecStart=/opt/order_bot/.venv/bin/python -m bot.main
  Restart=always

  [Install]
  WantedBy=multi-user.target
  ```
  `sudo systemctl enable --now orderbot`. Первый вход юзербота сделайте вручную через
  `python -m bot.main`, потом запускайте как сервис.
- Бесплатные хостинги с засыпанием (Render free и т.п.) не подходят: бот на polling
  должен работать постоянно.

## Структура

```
order_bot/
├── bot/
│   ├── main.py       # запуск: бот + юзербот + цикл бесплатного канала
│   ├── config.py     # настройки из .env
│   ├── detector.py   # распознавание заказов: ключевые слова, бюджет, маскировка контактов
│   ├── publisher.py  # фильтр → дубли → публикация, бесплатный канал с задержкой
│   ├── handlers.py   # хендлеры: сообщения групп, выдача контакта, /stats, /id
│   ├── userbot.py    # юзербот на Telethon
│   ├── formatter.py  # тексты постов и кнопки
│   ├── db.py         # SQLite: заказы и открытые контакты
│   └── models.py
├── tests/test_detector.py
├── requirements.txt
└── .env.example
```

## Настройка фильтра

Всё в `bot/detector.py`:
- `WORK_TYPES` — типы работ и корни слов;
- `REQUEST_MARKERS` — признаки просьбы («нужна», «хто може»…);
- `AD_MARKERS` — признаки рекламы авторов, такие сообщения отбрасываются.

Первую неделю просматривайте канал и группы-источники и дополняйте списки.
Проверка: `pip install pytest && python -m pytest`.
